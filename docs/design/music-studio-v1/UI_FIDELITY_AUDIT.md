# Music Studio UI fidelity audit

This checkpoint ports the Claude source designs into the existing native Web
Components UI without changing the simulation service or its safety boundary.

## Verified in browser

- App shell: 48px top bar, 212px navigation rail, global player, responsive collapse.
- Sidebar: project navigation, Work group, system links, active route state, keyboard hints.
- Projects: workspace header, search/sort surface, tabs, project table, durable-state note.
- Project Home: project metadata, current-version waveform, brief, generations, jobs, Ableton, references, activity.
- Create: brief-first composition form, duration/version controls, reference panel, Lucas guidance, recent prompts.
- Results: blind review header, status/progress, candidate grid, audio controls, review inspector, next-step guidance.

## Constraints preserved

- No Node, bundler, or framework added.
- Existing API routes and simulation actions remain the source of behavior.
- Provider/model identity stays out of listener-facing candidate cards.
- Simulation remains explicit; the UI does not claim real Ableton writes.
- Hex colors are centralized in `tokens.css`; components consume semantic tokens.
- Waveform paths are generated by `ui/lib/waveform.js` and now emit valid closed SVG paths.
